## Technical Stack & Architecture

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Framer Motion
- **Design Philosophy:** Universal Frontend Design Constitution (anti-AI slop, zero-pill metadata discipline, strict typographic hierarchy, glassmorphism, responsive 1440px baseline)
- **Backend Architecture:** Native PHP 8.x with PDO prepared statements & session management
- **Database Architecture:** Normalized MySQL / MariaDB (`database.sql`)
- **Target Hosting:** Truehost Shared Hosting with cPanel (No Supabase, No Firebase, No persistent Node runtime required on production host)
